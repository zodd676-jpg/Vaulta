# Mirage Wallet

Игровой симулятор кошелька. Все суммы и токены вымышленные, это не настоящий кошелёк и не подтверждение средств. Пометки «Демо» оставлены специально.

Сайт: Settings → Pages → Deploy from a branch → `main` → `/ (root)`.
На телефоне: открой сайт в Safari → «Поделиться» → «На экран Домой».
